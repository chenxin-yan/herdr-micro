# Use a minimal JSON Lines Device Protocol

The Deck and Host exchange compact, newline-delimited JSON over CircuitPython's dedicated USB CDC data stream. The protocol is unversioned; instead, both hellos carry the shared app version (single source: package.json, stamped onto the device at deploy) and an exact mismatch fails closed with a redeploy-bundle screen — the Host auto-updates while the Device Bundle only updates on re-copy, so drift is the named threat. It has bounded frames, complete last-write-wins Render Snapshots, fire-and-forget inputs and HID commands, and no acknowledgements, request IDs, sequence numbers, persistence, heartbeats, or capability negotiation. This keeps both implementations inspectable and lets malformed input resynchronize at the next newline.
